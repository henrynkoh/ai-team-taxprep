“Seattle tax pros: if your client has W-2, RSUs, an Airbnb *and* an AFH, TurboTax stops being ‘basic.’”

**[Problem — 3–12s]**  
“Depreciation, Form 4562, passive vs non-passive, RSU basis — the stack gets fragile fast.”

**[Solution — 12–28s]**  
“We run a 7-day **educational** cohort: full TurboTax Desktop workflow map + prompt library using **Claude, ChatGPT, and Gemini** side-by-side — cross-check everything before filing.”

**[CTA — 28–45s]**  
“Comment SYLLABUS or link in bio. Tax professionals only. Educational — not personal advice.”

**On-screen text:** `Seattle · TurboTax Desktop · 3 LLMs · 7 days`
