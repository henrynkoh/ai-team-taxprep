## 본문 구조 제안

### 1) 문제 제기

미국 **북서부(시애틀)** 클라이언트 중 **테크 W-2·RSU**와 **단기임대**, **AFH**가 같은 신고서에 올라오는 경우, **소프트웨어 화면 순서**와 **증빙 체계**가 어긋나기 쉽습니다.

### 2) 무엇을 배우는가

- **TurboTax Desktop** 기준 **스크린 맵**  
- **Form 4562·감가상각** 입력 시 **주의 연도·입주/사용일** (실제 과정에서는 **당해 연도 법령·공지** 확인 필수)  
- **패시브/논패시브·평균 숙박일** 등 **사실관계 기록**  
- **Claude / ChatGPT / Gemini**에 동일 프롬프트 → **출력 차이 비교**로 환각 줄이기  

### 3) 7일 로드맵 한눈에 (불릿)

1일~7일 요약은 네이버 글과 동일하게 **표준 시즌 커리큘럼** 목차를 짧게 인용.

### 4) 오픈 리소스 안내

GitHub 등에 **Next.js 커리큘럼 뷰어**가 있다면 링크: `/curriculum/standard`, `/prompts` 등 **경로 예시**는 README 기준으로 표기.

### 5) 맺음 + CTA

실무에 적용할 때는 **반드시** IRS Pub·Form 설명서·현재 TurboTax 빌드와 대조.  
댓글 또는 폼으로 **“실러버스 요청”** (실무자 한정 문구 권장).
