# Quickstart

Get the Seattle Combo Tax Curriculum app running in under five minutes.

## Prerequisites

- **Node.js** 20 LTS (or 22) and **npm**
- A terminal and a web browser

## Install and run

```bash
cd seattle-tax-curriculum
npm install
npm run dev
```

Open **http://localhost:3000**.

## First clicks (2 minutes)

1. **Home** — Read the positioning and daily rhythm.
2. Pick a track: **Standard** (`/curriculum/standard`) or **Advanced** (`/curriculum/advanced`).
3. Open **Day 1** and skim objectives, exercises, and deliverables.
4. Open **Prompts** (`/prompts`) → choose **Standard** or **Advanced** → use **Copy** on one prompt to see the disclaimer appended.

## Production build (optional)

```bash
npm run build
npm start
```
